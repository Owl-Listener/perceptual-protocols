# perceptual-protocols

A family of protocols for how AI systems perceive, interpret, and respond to human context — part of the [Owl-Listener](https://github.com/Owl-Listener) design research practice.

## Protocols

| Folder | Purpose |
|--------|---------|
| [`mood-protocol/`](https://github.com/Owl-Listener/mood-protocol) | How AI systems read and respond to emotional tone |
| [`vocab-protocol/`](./vocab-protocol/) | How AI systems handle language register and vocabulary matching |
| [`critique-protocol/`](./critique-protocol/) | How AI systems give and receive critique |

## Structure

Each protocol lives in its own subfolder (or linked repo) and follows a shared shape:

- **What it is** — a one-paragraph definition
- **Why it matters** — the design rationale
- **How it works** — the protocol mechanics
- **Examples** — annotated cases
- **Open questions** — what's unresolved
